= O que há de novo no ONTAP Mediator?
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Novos aprimoramentos para o ONTAP Mediator são fornecidos a cada nova versão.


NOTE: Para obter informações sobre a versão do sistema operacional e do SCST, consulte o link:support-matrix.html["Matriz de suporte"].

[cols="25,75"]
|===


| Versão do ONTAP Mediator | Melhorias 


 a| 
1.12.1
 a| 
* Suporte para RHEL:
+
** Compatível: 10.1 e 9.7.
** Recomendado: 10.2, 10.0, 9.8, 9.6, 9.4 e 8.10.


* Suporte para Rocky Linux 10.2, 9.8 e 8.10.
* Suporte para Oracle Linux 10.1 e 9.8 com kernels rhck e uek.
* A partir do ONTAP Mediator 1.12.1 e ONTAP 9.19.1, uma única instância do ONTAP Mediator configurada com HTTPS pode monitorar as seguintes configurações simultaneamente:
+
** Um máximo de dez configurações IP de quatro nós ou cinco de oito nós do MetroCluster, se instaladas em um host com CPU de 8 núcleos e pelo menos 16GB de RAM. Veja link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["Utilize ONTAP Mediator para monitorar várias configurações de IP MetroCluster"^].
** Uma configuração IP de quatro nós MetroCluster e uma relação de sincronização ativa entre pares SnapMirror, se instalada em um host com CPU de 2 núcleos. Veja link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/mediator-install-task.html#ontap-mediator["Configure o ONTAP Mediator para a sincronização ativa do SnapMirror"^].


* Inclui uma nova ferramenta para reparar uma instalação SCST corrompida. Após instalar o ONTAP Mediator, você pode encontrar a ferramenta em  `/usr/local/bin/mediator_repair_scst`. Você pode usar a ferramenta após uma atualização do sistema operacional, caso o sistema operacional atualizado exija um patch SCST que não esteja disponível no pacote SCST padrão.

1,12
 a| 
* Suporte para RHEL:
+
** Compatível: 10.1 e 9.7.
** Recomendado: 10.2, 10.0, 9.8, 9.6, 9.4 e 8.10.


* Suporte para Rocky Linux 10.2, 9.8 e 8.10.
* Suporte para Oracle Linux 10.1 e 9.7 com kernels rhck e uek.
* A partir do ONTAP 9.19.1 e ONTAP Mediator 1.12, você pode configurar um ONTAP Mediator que utiliza HTTPS para comunicação em configurações IP do MetroCluster. O HTTPS proporciona maior segurança ao criptografar sessões inteiras usando SSL/TLS. Você pode optar por instalar o ONTAP Mediator com suporte apenas para HTTPS. O pacote SCST não é instalado se este método de instalação for utilizado. link:../install/prepare-install.html#https-iscsi-installation["Saiba mais sobre as opções de instalação HTTPS e iSCSI para ONTAP Mediator"].

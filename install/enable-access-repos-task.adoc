= Forneça acesso ao repositório para a instalação do ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]

.Passos
. Determine quais repositórios precisam ser acessados, conforme mostrado na tabela a seguir:

. Use um dos seguintes procedimentos para habilitar o acesso aos repositórios listados acima, para que o ONTAP Mediator possa acessar os pacotes necessários durante o processo de instalação.
+

NOTE: Se o ONTAP Mediator tiver dependências de módulos Python presentes nos repositórios "extras" e "optional", ele poderá precisar acessar os arquivos  `rhel-X-for-x86_64-extras-rpms` e  `rhel-X-for-x86_64-optional-rpms`.

+
.Procedimento para sistema operacional Oracle Linux 10.x
[%collapsible]
====
Utilize este procedimento se o seu sistema operacional for *Oracle Linux 10.x* para habilitar o acesso aos repositórios:

.Passos
.. Inscreva-se no repositório necessário:
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
----
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
----
+
O exemplo a seguir mostra a execução deste comando:

+
[listing]
----
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
Repository 'ol-10-for-x86_64-baseos-rpms' is enabled for this system.
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
Repository 'ol-10-for-x86_64-appstream-rpms' is enabled for this system.
----
.. Execute o seguinte comando para listar os repositórios habilitados:
+
[source, cli]
----
yum repolist
----
+
Os repositórios recém-assinados devem aparecer na lista.

.Procedimento para o sistema operacional CentOS 7.x
[%collapsible]
====
Use este procedimento se o seu sistema operacional for *CentOS 7.x* para habilitar o acesso aos repositórios:


NOTE: Os exemplos a seguir mostram um repositório para o CentOS 7.6 e podem não funcionar em outras versões do CentOS. Use o repositório correspondente à sua versão do CentOS.

.Passos
.. Adicione o repositório C7.6.1810 - Base. O repositório de vault C7.6.1810 - Base contém o pacote "kernel-devel" necessário para o ONTAP Mediator.
.. Adicione as seguintes linhas a /etc/yum.repos.d/CentOS-Vault.repo.
+
[source, cli]
----
[C7.6.1810-base]
name=CentOS-7.6.1810 - Base
baseurl=http://vault.centos.org/7.6.1810/os/$basearch/
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
----
.. Execute o seguinte comando para listar os repositórios habilitados:


[source, cli]
----
yum repolist
----
O exemplo a seguir mostra a execução deste comando. O repositório CentOS-7.6.1810 - Base deve aparecer na lista.

.Procedimento para os sistemas operacionais Rocky Linux 10, 9 ou 8
[%collapsible]
====
Use este procedimento se o seu sistema operacional for *Rocky Linux 10*, *Rocky Linux 9* ou *Rocky Linux 8* para habilitar o acesso aos repositórios:

.Passos
.. Inscreva-se nos repositórios necessários:
+
[source, cli]
----
dnf config-manager --set-enabled baseos
----
+
[source, cli]
----
dnf config-manager --set-enabled appstream
----
.. Realize uma `clean` operação:
+
[source, cli]
----
dnf clean all
----
.. Verifique a lista de repositórios:
+
[source, cli]
----
dnf repolist
----


....
[root@localhost ~]# dnf config-manager --set-enabled baseos
[root@localhost ~]# dnf config-manager --set-enabled appstream
[root@localhost ~]# dnf clean all
[root@localhost ~]# dnf repolist
repo id                        repo name
appstream                      Rocky Linux 10 - AppStream
baseos                         Rocky Linux 10 - BaseOS
[root@localhost ~]#
....
....

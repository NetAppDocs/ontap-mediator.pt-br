= Verifique o status da instalação do ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após instalar o ONTAP Mediator, verifique se ele está funcionando corretamente.

.Passos
. Veja o status do ONTAP Mediator:
+
[source, cli]
----
systemctl status ontap_mediator
----

. Veja o status do SCST:
+
[source, cli]
----
systemctl status mediator-scst
----
+

NOTE: Se você instalou ONTAP Mediator 1.12 ou posterior com suporte apenas para HTTPS, o pacote SCST não está instalado e você pode ignorar esta etapa.

. Confirme as portas utilizadas pelo ONTAP Mediator:
+
[source, cli]
----
netstat -anlt | grep -E '3260|31784'
----
+
....

         tcp   0   0 0.0.0.0:3260    0.0.0.0:*      LISTEN

         tcp6  0   0 :::3260         :::*           LISTEN
....

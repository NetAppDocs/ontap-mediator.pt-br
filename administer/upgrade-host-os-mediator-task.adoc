= Atualize o sistema operacional do host e reinstale ou atualize ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para atualizar o sistema operacional do host do ONTAP Mediator com SCST instalado para uma versão mais recente, você deve desinstalar ONTAP Mediator. Após a atualização do sistema operacional, você pode reinstalar sua versão atual do ONTAP Mediator ou atualizar para uma versão mais recente.

.Sobre esta tarefa
* Esta tarefa aplica-se às versões do ONTAP Mediator com o SCST instalado. Se você instalou ONTAP Mediator 1.12 ou posterior com suporte apenas para HTTPS, o pacote SCST não está instalado e você pode atualizar o sistema operacional do host sem afetar o ONTAP Mediator. Consulte a documentação do fornecedor do sistema operacional do host para obter instruções de atualização do sistema operacional.
* Se você precisar apenas atualizar o kernel do sistema operacional do host para uma versão compatível, sem atualizar para uma nova versão do sistema operacional, consulte link:host-maintenance-task.html["Manter o sistema operacional do host para o ONTAP Mediator"] em vez disso.
* Antes de atualizar o sistema operacional do host para ONTAP Mediator com a ferramenta leapp-upgrade, link:uninstall-mediator-task.html["Desinstalar o ONTAP Mediator"]. A ferramenta verifica se há novas versões de RPM nos repositórios registrados.
* O instalador do ONTAP Mediator instala um arquivo .rpm, que a ferramenta leapp-upgrade inclui na busca. Como o instalador descompacta o arquivo em vez de baixá-lo de um repositório registrado, a ferramenta não consegue encontrar uma atualização. Você deve usar a ferramenta leapp-upgrade para desinstalar o pacote.


.Passos
. Faça backup dos arquivos de registro:
+
....
[rootmediator-host ~]# tar -czf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator ./log ./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]# tar -tf ontap_mediator_file_backup.tgz
./log/
./log/ontap_mediator.log
./log/scstadmin.log
./log/ontap_mediator_stdout.log
./log/ontap_mediator_requests.log
./log/install_20230419134611.log
./log/scst.log
./log/ontap_mediator_syslog.log
./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]#
....
. Faça a atualização com a ferramenta leapp-upgrade:
+
....
[rootmediator-host ~]# leapp preupgrade --target 9.8
  ..<snip upgrade checks>..
  ..<fix issues found>..
[rootmediator-host ~]# leapp upgrade --target 9.8
  ..<snip upgrade>..
[rootmediator-host ~]# cat /etc/os-release | head -2
NAME="Red Hat Enterprise Linux"
VERSION="8.4 (Ootpa)"
[rootmediator-host ~]#
....
. Reinstale o ONTAP Mediator:
+

NOTE: Execute os passos restantes imediatamente após reinstalar o ONTAP Mediator para evitar a perda de arquivos de log.

+
....
[rootmediator-host ~]# ontap-mediator-1.12.1/ontap-mediator-1.12.1

ONTAP Mediator: Self Extracting Installer

  ..<snip installation>..
[rootmediator-host ~]#
....
. Pare o ontap_mediator:
+
....
[rootmediator-host ~]# systemctl stop ontap_mediator
[rootmediator-host ~]#
....
. Substitua os arquivos de log:
+
....
[rootmediator-host ~]# tar -xf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator
[rootmediator-host ~]#
....
. Inicie o ontap_mediator:
+
....
[rootmediator-host ~]# systemctl start ontap_mediator
[rootmediator-host ~]#
....
. Reconecte todos os clusters ONTAP ao ONTAP Mediator atualizado:

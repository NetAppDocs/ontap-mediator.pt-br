[[confirm-the-listening-ports]]
== Confirme as portas de escuta

. Confirme as portas utilizadas pelo ONTAP Mediator:
+

NOTE: Para uma instalação somente HTTPS, espere apenas a porta 31784. Os listeners da porta 3260 no exemplo abaixo se aplicam quando o SCST está instalado.

+
[source, cli]
----
netstat -anlt | grep -E '3260|31784'
----
+
[listing]
----
[root@scspr1905507001 ~]# netstat -anlt | grep -E '3260|31784'

         tcp   0   0 0.0.0.0:31784   0.0.0.0:*      LISTEN

         tcp   0   0 0.0.0.0:3260    0.0.0.0:*      LISTEN

         tcp6  0   0 :::3260         :::*           LISTEN
----

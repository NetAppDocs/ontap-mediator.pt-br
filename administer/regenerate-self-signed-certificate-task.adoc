= Regenere um certificado autoassinado temporário para o host do ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Regenere um certificado temporário autoassinado para o host atual quando uma alteração no nome do host ou no endereço IP invalidar o certificado existente.


NOTE: Este procedimento só é compatível com sistemas que executam o ONTAP Mediator 1.7 ou posterior.

.Sobre esta tarefa
* Execute esta tarefa no host Linux onde você instalou o ONTAP Mediator.
* Você só pode executar esta tarefa se os certificados autoassinados gerados tiverem se tornado obsoletos devido a alterações no nome do host ou no endereço IP do host após a instalação do ONTAP Mediator.
* Após o certificado autoassinado temporário ser substituído por um certificado confiável de terceiro, você _não_ deve usar esta tarefa para regenerar um certificado. A ausência de um certificado autoassinado fará com que este procedimento falhe.


.Etapa
Para gerar um novo certificado autoassinado temporário para o host atual, execute a seguinte etapa:

. Reinicie o ONTAP Mediator:
+
`./make_self_signed_certs.sh overwrite`

= Alterar o nome de usuário e a senha do ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Altere o nome de usuário ou a senha do ONTAP Mediator no host Linux onde o ONTAP Mediator está instalado.



[[change-the-username]]
== Alterar o nome de usuário

Você pode alterar o nome de usuário seguindo o procedimento abaixo.

.Sobre esta tarefa
Execute esta tarefa no host Linux onde você instalou o ONTAP Mediator.

Caso você não consiga executar esse comando, talvez seja necessário executá-lo usando o caminho completo, conforme mostrado no exemplo a seguir:

`/usr/local/bin/mediator_username`

.Passos
Altere o nome de usuário escolhendo uma das seguintes opções:

* *Opção (a)*: Execute o comando `mediator_change_user` e responda às solicitações conforme mostrado no exemplo a seguir:
+
....
 [root@mediator-host ~]# mediator_change_user
 Modify the Mediator API username by entering the following values:
     Mediator API User Name: mediatoradmin
                   Password:
 New Mediator API User Name: mediator
 The account username has been modified successfully.
 [root@mediator-host ~]#
....
* *Opção (b)*: Execute o seguinte comando:
+
`MEDIATOR_USERNAME=mediator MEDIATOR_PASSWORD=mediator2 MEDIATOR_NEW_USERNAME=mediatoradmin mediator_change_user`

+
[listing]
----
 [root@mediator-host ~]# MEDIATOR_USERNAME=mediator MEDIATOR_PASSWORD='mediator2' MEDIATOR_NEW_USERNAME=mediatoradmin mediator_change_user
 The account username has been modified successfully.
 [root@mediator-host ~]#
----




[[change-the-password]]
== Alterar a senha

Você pode alterar a senha usando o procedimento a seguir.

.Sobre esta tarefa
Execute esta tarefa no host Linux onde você instalou o ONTAP Mediator.

Caso você não consiga executar esse comando, talvez seja necessário executá-lo usando o caminho completo, conforme mostrado no exemplo a seguir:

`/usr/local/bin/mediator_change_password`

.Passos
Altere a senha escolhendo uma das seguintes opções:

* *Opção (a)*: execute o `mediator_change_password` comando e responda às solicitações conforme mostrado no exemplo a seguir:
+
....
 [root@mediator-host ~]# mediator_change_password
 Change the Mediator API password by entering the following values:
    Mediator API User Name: mediatoradmin
              Old Password:
              New Password:
          Confirm Password:
 The password has been updated successfully.
 [root@mediator-host ~]#
....
* *Opção (b)*: Execute o seguinte comando:
+
`MEDIATOR_USERNAME=mediatoradmin MEDIATOR_PASSWORD=mediator1 MEDIATOR_NEW_PASSWORD=mediator2 mediator_change_password`

+
O exemplo mostra que a senha foi alterada de "mediator1" para "mediator2".

+
....
 [root@mediator-host ~]# MEDIATOR_USERNAME=mediatoradmin MEDIATOR_PASSWORD=mediator1 MEDIATOR_NEW_PASSWORD=mediator2 mediator_change_password
 The password has been updated successfully.
 [root@mediator-host ~]#
....

= Manter o sistema operacional do host para o ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Garanta que o sistema operacional host do ONTAP Mediator receba manutenção regular para obter o desempenho ideal.



[[reboot-the-host]]
== Reinicialize o host

Reinicialize o host somente quando os clusters estiverem saudáveis. Os clusters não podem responder a falhas enquanto o ONTAP Mediator estiver offline. Defina um horário para manutenção antes de reinicializar.

O ONTAP Mediator retoma automaticamente a operação durante uma reinicialização e volta a estabelecer os relacionamentos configurados anteriormente com os clusters do ONTAP.



[[host-package-updates]]
== Atualizações do pacote do host

Atualize qualquer biblioteca ou pacote yum, exceto o kernel. Reinicialize o host, se necessário, para que as alterações entrem em vigor. Agende uma janela de serviço antes de reinicializar o host.

Se você instalar o  `yum-utils`pacote, use o  `needs-restarting`comando para detectar se alguma alteração no pacote requer reinicializar.

Reinicialize o sistema após atualizar as dependências do ONTAP Mediator, pois as alterações não entram em vigor imediatamente.



[[upgrade-the-host-os-kernel]]
== Atualize o kernel do sistema operacional do host

O SCST deve ser compilado para o kernel que você está usando. Para atualizar o sistema operacional, você precisa agendar um período de manutenção.

.Antes de começar
Os seguintes requisitos se aplicam quando o pacote SCST é instalado com ONTAP Mediator.

* Você pode atualizar todos os pacotes de biblioteca, exceto o kernel, mas talvez seja necessário reinicializar para aplicar as alterações no ONTAP Mediator. Agende uma interrupção do serviço caso precise reinicializar.
* Você deve manter o kernel do sistema operacional atualizado. Atualize o núcleo do kernel para uma versão compatível listada em link:../release-notes/support-matrix.html#scst-support-matrix["Matriz de versões do ONTAP Mediator"]. Você precisa reinicializar o sistema, portanto planeje uma janela de manutenção para a interrupção.
+
** Desinstale o módulo do kernel SCST antes de reinicializar e reinstale-o em seguida.
** Prepare uma versão compatível do SCST para reinstalar antes de iniciar a atualização do kernel do sistema operacional.





NOTE: Se você instalou ONTAP Mediator 1.12 ou posterior com suporte apenas para HTTPS, o pacote SCST não está instalado e o kernel do sistema operacional host pode ser atualizado sem afetar ONTAP Mediator. Consulte a documentação do seu sistema operacional host para obter instruções de atualização.

.Passos
Siga estes passos para atualizar o kernel do sistema operacional do host.


NOTE: Antes de atualizar o kernel, verifique se o sistema operacional e a versão do ONTAP Mediator são compatíveis. Para obter informações sobre as versões compatíveis, consulte o link:../release-notes/support-matrix.html#os-support-matrix["Matriz de suporte do SO"].

. Pare o ONTAP Mediator.
. Desinstale o pacote SCST, veja <<Realizar manutenção do host>>. (O SCST não oferece um mecanismo de atualização.)
. Atualize o sistema operacional e reinicialize.
. Reinstale o pacote SCST.
. Reative o ONTAP Mediator.




[[perform-host-maintenance]]
== Realizar manutenção do host

A atualização do kernel da VM pode causar problemas de compatibilidade com os módulos SCST. Desinstale e reinstale o SCST manualmente.


NOTE: Se você instalou ONTAP Mediator 1.12 ou posterior com suporte apenas para HTTPS, o pacote SCST não está instalado e você pode ignorar esta tarefa.

[[step-2-install-scst]]
=== Etapa 2: Instalar o SCST

Para instalar o SCST manualmente, você precisa do pacote tar do SCST que é usado para a versão instalada do ONTAP Mediator (consulte o <<scst-bundle-table,Tabela SCST>>).

.Sobre esta tarefa
* Execute esta etapa antes de instalar o ONTAP Mediator. Se a versão do SCST que você está usando for mais recente do que a versão incluída no instalador do ONTAP Mediator, o instalador ignorará esta etapa.
* Em alguns cenários, a instalação padrão do SCST no sistema operacional atualizado pode falhar porque o sistema operacional atualizado requer uma correção.
+
A partir do ONTAP Mediator 1.12.1, se a instalação falhar, você pode usar a ferramenta de reparo SCST localizada em  `/usr/local/bin/mediator_repair_scst` para reparar a instalação.

+
Se o sistema operacional atualizado exigir uma correção, a ferramenta a contém para a versão do SCST fornecida no pacote do ONTAP Mediator. A ferramenta  `mediator_repair_scst` é uma ferramenta autônoma, separada do instalador principal e está incluída no arquivo do ONTAP Mediator  `tgz`. Ela não afeta a instalação ou os caminhos de atualização do ONTAP Mediator.



.Passos
. Execute os seguintes comandos de instalação no `scst` diretório:
+
.. `make 2release`
.. `make scst_install`
.. `make usr_install`
.. `make iscsi_install`
.. `make scstadm_install`
.. `depmod`
+
[NOTE]
====
Se você estiver realizando uma instalação pela primeira vez e quiser pré-instalar o ONTAP Mediator, execute o seguinte comando antes de prosseguir para a próxima etapa:

`mkdir -p /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys`

====
.. `cp scst/src/certs/scst_module_key.der /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/`
.. `patch /etc/init.d/scst < /opt/netapp/lib/ontap_mediator/systemd/scst.patch`
+

NOTE: Se você pré-instalar o SCST antes do ONTAP Mediator durante a primeira instalação, ignore esta etapa. O instalador aplica os patches relevantes do SCST.



. Opcionalmente, se o Secure Boot estiver ativado, antes de reinicializar, execute as seguintes etapas:
+
.. Determine o nome de cada arquivo para os `scst_vdisk`, `scst` e `iscsi_scst` módulos:
+
....
[root@localhost ~]# modinfo -n scst_vdisk
[root@localhost ~]# modinfo -n scst
[root@localhost ~]# modinfo -n iscsi_scst
....
.. Determine a versão do kernel:
+
....
[root@localhost ~]# uname -r
....
.. Assine cada arquivo de módulo com o kernel:
+
....
[root@localhost ~]# /usr/src/kernels/<KERNEL-RELEASE>/scripts/sign-file \sha256 \
/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.priv \
/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der \
_module-filename_
....
.. Instale a chave UEFI com o firmware.
+
As instruções para instalar a chave UEFI encontram-se em:

+
`/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/README.module-signing`

+
A chave UEFI gerada está localizada em:

+
`/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der`



. Reinicialize o sistema:
+
`reboot`





[[host-changes-to-the-hostname-or-ip]]
== Alterações do host no nome do host ou no endereço IP

.Sobre esta tarefa
* Execute esta tarefa no host Linux onde você instalou o ONTAP Mediator.
* Faça isso somente se os certificados autoassinados não forem mais válidos porque o nome do host ou o endereço IP mudaram após a instalação do ONTAP Mediator.
* Após o certificado autoassinado temporário ser substituído por um certificado confiável de terceiro, você _não_ deve usar esta tarefa para regenerar um certificado. Se você não tiver um certificado autoassinado, não poderá usar este procedimento.


.Etapa
Crie um certificado autoassinado temporário para o host atual:

. Reinicie o ONTAP Mediator:
+
`./make_self_signed_certs.sh overwrite`

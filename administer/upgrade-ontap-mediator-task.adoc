= Atualize o ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para atualizar o ONTAP Mediator para uma versão mais recente sem atualizar o sistema operacional do host, baixe o pacote de instalação da nova versão e execute o instalador no host em que o ONTAP Mediator já está instalado.


NOTE: Se você precisar atualizar o sistema operacional do host para uma nova versão e reinstalar ou atualizar o ONTAP Mediator como parte desse processo, consulte link:upgrade-host-os-mediator-task.html["Atualize o sistema operacional do host e ONTAP Mediator"].

.Antes de começar
* Verifique se o seu host atende aos pré-requisitos descritos em link:../install/prepare-install.html["Prepare-se para instalar o ONTAP Mediator"], incluindo os requisitos de host, firewall e sistema operacional.
* Faça o download do pacote de instalação da nova versão. Consulte link:../install/download-install-pkg-task.html["Baixe o pacote de instalação do ONTAP Mediator"].
* NetApp recomenda verificar a assinatura de código do novo pacote de instalação. Consulte link:../install/verify-code-signature-task.html["Verifique a assinatura de código do pacote de instalação do ONTAP Mediator"].


.Sobre esta tarefa
Analise as seguintes informações antes de atualizar o ONTAP Mediator.

* Você deve atualizar o ONTAP Mediator para a versão mais recente. As versões antigas ainda funcionam com todas as versões do ONTAP, mas as versões mais recentes incluem correções de segurança para componentes de terceiros.
* Ao atualizar para uma nova versão do ONTAP Mediator que inclui o pacote SCST, o instalador atualiza automaticamente para a versão recomendada do SCST, a menos que uma versão superior esteja disponível. Para instruções sobre como instalar manualmente uma versão superior do SCST, consulte link:host-maintenance-task.html["Manter o sistema operacional do host para o ONTAP Mediator"]. Para versões compatíveis, consulte o link:../release-notes/support-matrix.html#scst-support-matrix["Matriz de suporte do SCST"].


[NOTE]
====
* Se a atualização falhar, talvez seja necessário tentar uma versão mais recente do ONTAP Mediator.
* A partir de 15 de junho de 2025, você não poderá instalar ou atualizar o ONTAP Mediator 1.9 e 1.8 porque os certificados de assinatura de código deles expiraram. Se a atualização falhar, use a versão de patch 1.9.1 do ONTAP Mediator.


====
* A partir do ONTAP 9.19.1 e do ONTAP Mediator 1.12, você tem a opção de instalar o ONTAP Mediator com suporte a iSCSI e HTTPS, ou com suporte apenas a HTTPS. Se você optar por instalar o ONTAP Mediator com suporte apenas a HTTPS, o pacote SCST não será instalado.
* Se você atualizar do ONTAP Mediator 1.11 ou anterior com o SCST instalado e escolher a opção somente HTTPS durante a atualização, o pacote SCST será desinstalado e a nova versão do ONTAP Mediator não conterá o pacote SCST.
* Se você planeja usar ONTAP Mediator para monitorar várias configurações de MetroCluster IP, o suporte depende do seu tipo de Mediator, versão do ONTAP e sistema operacional. Consulte link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["Utilize ONTAP Mediator para monitorar várias configurações de IP MetroCluster"^] para obter mais informações.
* A instalação do ONTAP Mediator com suporte apenas para HTTPS é compatível com os seguintes casos de uso:
+
** Você planeja usar apenas o ONTAP Mediator para monitorar seus clusters de sincronização ativa do SnapMirror.
** Você planeja configurar ONTAP Mediator com HTTPS para monitorar uma ou mais configurações de IP MetroCluster.


* ONTAP Mediator deve ser instalado com suporte para iSCSI e HTTPS no seguinte cenário:
+
** Você planeja configurar ONTAP Mediator com iSCSI para monitorar uma ou mais configurações de IP do MetroCluster.




* Ao executar o instalador em uma instalação existente do ONTAP Mediator, ele detecta a versão atual e solicita que você confirme a atualização:
+
`ONTAP Mediator will be upgraded from version <current-version> to <new-version>.`

+
`Do you wish to continue? Y(es)/n(o):`

* Como parte da atualização, o instalador captura um pacote de suporte da sua configuração anterior à atualização e migra o banco de dados antes de atualizar o software ONTAP Mediator.
* Para casos de uso de automação, você pode usar o comando  `./ontap-mediator-1.12.1/ontap-mediator-1.12.1 -y` para ignorar as solicitações do instalador.


.Passos
. Execute o instalador da nova versão e responda às solicitações conforme necessário:
+
[source, cli]
----
./ontap-mediator-1.12.1/ontap-mediator-1.12.1
----
+
[NOTE]
====
Para ignorar a verificação de assinatura durante a atualização, use o
`./ontap-mediator-1.12.1/ontap-mediator-1.12.1 --skip-code-signature-check` comando

====
+
O instalador detecta a instalação existente e solicita que você faça a atualização. Em seguida, instala os pacotes necessários e migra sua configuração.
